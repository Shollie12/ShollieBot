# **Welcome to Sholliebot v1**
Sholliebot will change the world...
Featuring all new, never seen before commands, Sholliebot will be sure to keep you entertained for hours.
Sholliebot's core functionality lies within it's state-of-the-art generative chat capabilities ran locally off of a LLM of your choosing through KoboldCpp.
This is then supported with a variety of useful utility commands to keep things in check.
